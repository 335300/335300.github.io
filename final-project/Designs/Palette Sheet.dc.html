Changes to the starting tokens

  • Dark primary-tint / info-tint #1E3354 → #1B2E4D. Primary text (#9BBDF0) on the old tint measured Lc 59,8 — just under the 60 floor for readable text. The new value is 1 step darker and reaches Lc 61.
  • Added dark warning-ink #E8B04A, gold-ink #F2C14E, info #9BBDF0. The starting set had no dark equivalents; on dark grounds the base colours already pass as text.
  • Dark logo #A78BFA is graphic-only. It measures Lc ≈ 48, fine for a mark, so the “Centwise” wordmark is set in ink.
  • No other values changed. Light warning #B45309 (Lc 70) and ink-muted (Lc 72 on bg) pass for labels but not body text, so body-size warnings use warning-ink and ink-muted is restricted to ≥ 13px.
  • Chart fills under 3:1 (e.g. chart-2 #E69F00, chart-3 #56B4E9 on white) are allowed only with direct value labels, which WCAG 1.4.11 accepts as the information carrier.
